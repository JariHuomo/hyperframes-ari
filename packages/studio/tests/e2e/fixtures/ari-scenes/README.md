# Portable scene-time fixture

Synthetic shop and packaging; no customer assets or network calls. Archivo is redistributed under the adjacent OFL. The UAT copies GSAP from the installed workspace dependency.

The headline enters over 0.9 scene seconds and its source holds for 7 seconds. Hosts: A 0.12–5.60 s at ×1; B 5.60–7.00 s at ×1.5. The master export must retain the headline at 3.5 s and 6.9 s.

`assets/gsap.min.js` is a fail-closed preparation sentinel, not a vendored runtime. The test runner overwrites it with the installed dependency before opening the copied project.
